# Library Management System

A command-line Library Management System built using Python. The application allows users to manage books, track their availability, and save data for future use.

## Features

* Add Book
* View Books
* Search Book
* Borrow Book
* Return Book
* Save Books to File
* Load Books from File
* Book Availability Tracking

## Concepts Used

* Python Functions
* Lists
* Dictionaries
* Loops
* Conditional Statements
* File Handling
* Boolean Values
* User Input

## How to Run

1. Install Python.
2. Open a terminal in the project folder.
3. Run:

python library_management.py

## Data Storage

Books are stored in a text file (`books.txt`) and automatically loaded when the program starts.

Example:

Atomic Habits,James Clear,False

Rich Dad Poor Dad,Robert Kiyosaki,True
